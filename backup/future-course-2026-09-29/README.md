# Future-course backup

This backup was created on 29 September 2026 when the live Stigen course was reduced to one carefully developed chapter and one lecture.

Nothing in this folder is loaded by the application. It preserves the previous future-course material so it can be reviewed and restored deliberately instead of being deleted.

## Contents

- `site/content/lectures/lecture-02.json` through `lecture-60.json`: inactive future lectures.
- `site/content/lectures/index.full.json`: the former generated 60-lecture runtime index.
- `site/content/modules.full.json`: the former 12-chapter/module plan and all 60 titles.
- `site/lib/story-world.full.ts`: the former chapter, cast, episode-art, and story-object registry.
- `site/public/images/story/chapters/`: artwork for Chapters 2–11. Chapter 12 previously reused a general orientation image and therefore had no dedicated file to move.
- `site/public/images/story/episodes/`: dedicated artwork for Episodes 2–55. Episodes 56–60 previously reused a general fallback image and therefore had no dedicated files to move.

## Restore rule

Do not copy this whole backup into the live app. Review one teacher lesson with its textbook and homework references, improve one corresponding lecture, then move only that approved material back into the active locations documented in the project README.
