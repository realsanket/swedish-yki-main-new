# YKI pilot log: Days 1–7

*Started 16 November 2026 (third review). The plan's architecture is frozen (plan, "Freeze and pilot"). Run Days 1–7 as written in `YKI-LEARNER-DAYS-1-14.md`, fill in one row a day, and change the plan only from what this log shows. All thresholds below are this plan's own [Plan's own], not exam rules.*

## How to fill in a row

- **Actual minutes:** the real time from the start of review to the end of the log block, breaks not counted. Write the true number, even if it is far over 60.
- **New patterns:** how many new patterns the day taught (load rule 1: count sentence shapes, not cards; a card with two sentences is two patterns).
- **Recalled next day:** next morning, before the review block, cover the Swedish and say yesterday's new patterns from the English. Write how many came out right, for example 4/5.
- **Understood when spoken:** a helper or the audio (`YKI-AUDIO-LIST-DAYS-1-14.md`) says each new line once, in a new order. How many did you understand at once?
- **Changed independently:** how many new patterns could you change (a new detail or a new person) without looking at the model?
- **Typed independently:** how many could you type from the English cue? Spelling slips count as right if the word is clear.
- **G/A/R:** the day's Green, Amber or Red mark (plan section 1).
- **What was too much:** one line, in your own words: the block, the list or the task that did not fit.

## How to read the result (after Day 7)

1. Add up the actual minutes of the seven study days (1, 2, 3a, 3b, 4, 5, 6; not the light Day 7) and look at each day on its own.
2. If most days took 60–65 minutes, 60 minutes is realistic: keep the plan as it is.
3. If two or more days took over 70 minutes, 60 minutes is not realistic at this load: either plan 75–90-minute days, or cut new patterns to 4 a day and let the calendar slip (load rule 9).
4. If "recalled next day" is below about two thirds on two or more days, the load is too high even if the time fitted: fewer new patterns, not more review.
5. If you understood a line when spoken but could not recall it, you need more hearing before saying (rung 0), not more cards.
6. If "changed independently" is low, give the swap drill (ladder rung 2) more minutes before any new pattern.
7. If speaking is fine but "typed independently" is low, the problem is the keyboard or spelling, not the load: add 5 typing minutes, not a new day.
8. **Day 3b:** if it was Red, ran over 70 minutes, or is named under "too much", split it into 3b and 3c (same tasks, new details; load rule 9).
9. **Day 4:** the same rule: if it was Red, ran over 70 minutes, or is named under "too much", split it into 4a and 4b, and use the spare row for 4b.
10. Send the filled log with the first weekly teacher pack, and revise the plan only from this evidence: one change at a time, then run the next days.
