# Lecture pictures (Lectures 3-16)

Lectures 1 and 2 already have pictures. Save each new picture in
`site/public/images/story/episodes/` with the file name shown. Start every
prompt with the style block and cast block from [`README.md`](README.md). Each
lecture's object label (`story.object`) is already set in its JSON; only
`story.art` waits for the file.

## Lecture 3: The evening before the test

**File:** `episode-03-evening-before-test.webp` · **Object:** study notes and a phone

> A spring evening in a cosy Helsinki flat, soft fading daylight through a large
> window. Alex sits at a light-wood desk, tired but smiling, rubbing one eye and
> holding a pen over his open spiral notebook; an open textbook, blank study
> cards and a glass of water beside him. An open laptop shows a video call with
> Elin, who smiles kindly and rests her cheek on her pressed-together hands in a
